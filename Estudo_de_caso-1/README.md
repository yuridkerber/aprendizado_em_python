# Mini Projeto 1 — Análise de Vendas de E-commerce

Projeto de análise de dados de vendas utilizando **Python, NumPy, Pandas e Matplotlib**, com o objetivo de transformar dados brutos em insights estratégicos para o negócio.

### Objetivos
- Identificar os produtos mais e menos vendidos.
- Analisar o desempenho das categorias.
- Investigar tendências e sazonalidade nas vendas.
- Identificar as regiões com maior desempenho comercial.

### Tecnologias
- Python
- NumPy
- Pandas
- Matplotlib

### Propósito
Auxiliar na tomada de decisões estratégicas, otimizando estoques, direcionando campanhas de marketing e identificando oportunidades de crescimento por meio da análise de dados.
